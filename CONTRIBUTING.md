# Contributing to SOTI Custom Data Importer

First off, thank you for considering contributing to SOTI Custom Data Importer! It's people like you that make the tool better for everyone.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct (standard contributor covenant).

## How Can I Contribute?

### Reporting Bugs

- **Check if the bug has already been reported** by searching on the [GitHub issues](https://github.com/yannickweijenberg/CustomDataImporter/issues).
- If you can't find an open issue addressing the problem, [open a new one](https://github.com/yannickweijenberg/CustomDataImporter/issues/new).
- Use the **Bug Report** template if available.
- Include as much detail as possible: steps to reproduce, what you expected to happen, what actually happened, and any relevant logs.

### Suggesting Enhancements

- **Check if the enhancement has already been suggested**.
- [Open a new issue](https://github.com/yannickweijenberg/CustomDataImporter/issues/new) and describe the feature you'd like to see.
- Use the **Feature Request** template if available.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Scripting Guidelines

- Keep the UI responsive by using asynchronous calls where possible.
- Use the standard CSS variables defined in `src/styles.css` for consistent styling.
- Ensure PowerShell scripts follow the existing coding style for cross-platform compatibility where relevant.

## Questions?

Feel free to open an issue with the "question" label.
